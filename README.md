# 业务方案红蓝对抗与复核

一个用于工作坊和日常方案讨论的 AI Skill：红队针对方案提出有依据的挑战，蓝队回应并修改，主持人依据事实判断，帮助团队发现盲点、完善方案。

适用于运营方案、团队协作、服务设计和教学演练。一个人也可以使用：你提出方案，AI 模拟红队；需要时，AI 也可以模拟蓝队回应，供你判断和修改。

## 获取与安装

下载完整仓库，保留 `SKILL.md`、`references/` 和 `agents/` 的目录结构：

```bash
git clone https://github.com/Atange2023/operations-red-blue-review.git
```

将下载的文件夹按你使用的 AI 助手的 Skill 安装方式导入。若产品不支持导入 Skill，可将完整文件夹交给支持读取本地文件的 AI 助手，要求它先读取 `SKILL.md`。提交内部业务资料前，请遵守所在单位的数据使用要求。

## 开始试用

告诉 AI：

> 请启动业务方案红蓝对抗。我会给你一个方案，请你扮演红队，针对方案中的具体内容提出挑战，等我回应后再继续。

如果不知道怎样回应，也可以说：“请模拟蓝队替我逐条回应，并给出修订版。”AI 模拟的回应需要由方案负责人判断，不代表已经过独立评审或人工裁定。

## 工作坊怎么用

团队先交代方案、目标、事实和约束；需要时，主持人再提供变化事件。红队提出具体挑战，蓝队逐条回应，主持人结合证据判断，最后记录方案的修改和待确认事项。单向红队审查也可以直接使用，无须强行完成所有环节。

仓库的 `references/` 包含主持与评价建议，以及带初始材料、方案、变化事件和讲师参考判断的合成教学案例。时间和轮次由现场主持人决定。

## 使用范围

本 Skill 用于学习、方案讨论和复盘，不代替现场指挥、专业规程或有权限人员的决策。遇到正在发生或可能立即危及人身、行车或设备安全的事件，应停止演练，按现场应急制度联系授权岗位。
